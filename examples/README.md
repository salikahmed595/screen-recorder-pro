# Examples

Three standalone, zero-dependency pages in the PAICONS dark/lime theme. Open any file in Chrome or Edge
(or run `npx serve .` — `getDisplayMedia` needs `https://` or `http://localhost`). Nothing is uploaded.

| File | Best for | Flow |
|------|----------|------|
| `01-one-click.html` | The simplest possible recorder | One big button → pick a screen → record → download |
| `02-guided-steps.html` | First-time users | Choose → set up (live mic meter + camera preview) → record → save |
| `03-floating-studio.html` | Tutorials & demos | Draggable toolbar, pen / highlighter / arrow / box / laser, draggable face bubble, shortcuts (`?`) |

Each file is self-contained; the shared recorder core is inlined so you can copy a single file anywhere.
